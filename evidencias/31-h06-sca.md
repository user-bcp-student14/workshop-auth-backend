Consulta realizada el 2026-10-19. Solo se enviaron coordenadas Maven publicas
a OSV; no codigo, configuracion, credenciales ni datos del repositorio.

1. `mvn -B -ntp dependency:tree` antes: salida 0, 244 artefactos resueltos.
   [Arbol](23-h06-dependencias-antes.txt), [paquetes](24-h06-paquetes-antes.json).
2. POST `https://api.osv.dev/v1/querybatch`, cuerpo
   `{"queries":[{"package":{"ecosystem":"Maven","name":"group:artifact"},"version":"version"}]}`.
   Se incluyeron todos los alcances presentes, tambien test, no solo directas.
   [Respuesta antes](24-h06-osv-antes.json): 49 coincidencias paquete/advisory.
3. GET `https://api.osv.dev/v1/vulns/<id>` para cada identificador.
   [JSON completos](h06-advisories/) conservan rangos afectados, versiones
   corregidas, condiciones, aliases CVE y referencias de los mantenedores.
4. Despues: `mvn -B -ntp clean verify quarkus:build dependency:tree
   "-DoutputFile=evidencias\28-h06-dependencias-despues.txt"`: salida 0.
   243 artefactos resueltos, [respuesta OSV](29-h06-osv-despues.json):
   **0 coincidencias**. La comprobacion exige cero, sin allowlist/supresiones.
5. Prueba de correccion SCA: antes 49 != 0, salida 1
   ([evidencia](27-h06-sca-antes.txt)); despues 0 == 0, salida 0
   ([evidencia](29-h06-sca-despues.txt)).

La cifra no prueba explotabilidad ni ausencia global de CVE. No se auditaron
plugins Maven, binarios nativos ni un despliegue externo; no se ejecutaron
CodeQL/Dependency Review remotos y no se alteraron sus workflows.

## Eleccion de versiones y fuentes

- Quarkus **3.27.4 -> 3.27.6**: parche dentro de la misma linea LTS.
  3.27.4.1 corrige el bypass de paths pero mantiene Jackson 2.21.2;
  3.27.5/5.1/5.2 mantienen Jackson 2.21.5; 3.27.5.3 trae 2.21.6.
  3.27.6 es el primer BOM de esta linea que combina Netty 4.1.138.Final y
  Jackson 2.21.7, corrigiendo todos los rangos observados. Existe 3.27.6.1,
  pero no fue necesario para los avisos presentes ni para compatibilidad.
- Commons Text **1.9 -> 1.14.0**, ahora administrado por el BOM: se elimina
  el override, no se agrega dependencia. Se supera el minimo seguro 1.10.0
  y se conserva escapeHtml4. 1.15.0 requiere Commons Lang 3.20.0, mientras
  este BOM administra 3.18.0; no se introducen overrides innecesarios.
- Fuentes:
  [release 3.27.6](https://quarkus.io/blog/quarkus-3-27-6-released/),
  [BOM publicado](https://repo.maven.apache.org/maven2/io/quarkus/platform/quarkus-bom/3.27.6/quarkus-bom-3.27.6.pom),
  [metadatos BOM](https://repo.maven.apache.org/maven2/io/quarkus/platform/quarkus-bom/maven-metadata.xml),

## Aplicabilidad al uso local

- **Commons Text / CVE-2022-42889:** Apache condiciona RCE al uso inseguro de
  StringSubstitutor con entrada no confiable. El unico uso de produccion es
  LoginResponse.from, escapeHtml4; no se identifica ese vector aqui. Se
  actualiza igualmente el artefacto afectado, sin silenciar la alerta.
- **Quarkus / GHSA-qcxp-gm7m-4j5v:** requiere politicas HTTP por paths y/o
  recursos estaticos protegidos; application.properties no declara politicas
  quarkus.http.auth.permission y las dos rutas documentadas son publicas.
  No se demuestra bypass local; el componente afectado si esta presente.
  [Aviso del mantenedor](https://github.com/quarkusio/quarkus/security/advisories/GHSA-qcxp-gm7m-4j5v).
- **Jackson:** LoginRequest solo declara strings; no declara JsonView,
  JsonUnwrapped, JsonIgnore, tipado polimorfico, InetAddress ni tipos temporales.
  No se atribuyen esos vectores a este DTO. Los parsers reciben JSON no
  confiable y los avisos de limites/DoS justifican corregir el rango, sin
  afirmar una explotacion demostrada con la suite funcional.
- **Netty:** son transitivas del servidor HTTP. No se agregan manejadores
  propios de SNI/TLS, DNS, HAProxy, SPDY, Bzip2, multipart o WebSocket;
  su presencia no demuestra activacion de todos los vectores. HTTP/CORS/HTTP2
  pueden depender de configuracion y trafico de despliegue: no se descartan
  como falsos positivos. Se actualiza el conjunto alineado por BOM.
